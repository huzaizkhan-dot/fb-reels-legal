User Data Deletion

FB Reels Scheduler  ·  Effective 19 November 2026

This page explains how to have any data associated with the FB Reels Scheduler application deleted.

What the App stores

ItemWhere it lives
Facebook Page access tokenEncrypted secret in GitHub Actions
Page ID and Page nameGoogle Sheet and automation configuration
Scheduling records (times, captions, status, published post IDs)Google Sheet owned by the operator
Video filesNot retained — used transiently and discarded

How to request deletion

Option 1 — Revoke access immediately (fastest) In Facebook: Settings & privacy → Settings → Apps and Websites, select FB Reels Scheduler, and choose Remove. This invalidates the App's access token immediately, so it can no longer read or publish to any Page.
Option 2 — Request deletion by email Email huzaizkhan@gmail.com with the subject Data deletion request — FB Reels Scheduler, stating the Page(s) concerned. Deletion is completed within 30 days and confirmed by reply.

What gets deleted

  • All stored Page access tokens for the App — removed from GitHub Actions secrets.
  • All scheduling records associated with the named Page(s) — rows removed from the spreadsheet.
  • Any cached configuration referencing the Page.

What is not deleted

  • Posts already published to Facebook. Those are Facebook content, not App data; delete them in the Page itself.
  • Content already published and visible on the Page remains subject to Facebook's own controls.

Timeline

Access revocation via Option 1 takes effect immediately. Email-based deletion completes within 30 days of a verified request.

No third-party data

The App never collects data about Page followers, viewers, or any other individual. There is no third-party personal data to delete.
